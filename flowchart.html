🔄 Automated Refactoring Pipeline - Visual Guide

📋 Overview

This document provides visual flowcharts for the automated refactoring pipeline (Task 3C). The pipeline detects design smells, uses LLMs to generate refactorings, and creates pull requests with the suggestions.
